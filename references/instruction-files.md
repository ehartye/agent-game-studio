# Project instruction files

No Studio block is needed by default. Existing instructions often already identify the relevant records. Studio does not choose an authoritative file, reorganize host-specific sections or reconcile files automatically.

For requested instruction-file maintenance, follow the user's authorization and project conventions. Explicit delegation can authorize edits; Studio adds no line-by-line approval process. Preserve unrelated instructions.

If a pointer helps, use [this short template](templates/instruction-block.md) with actual existing wiki paths. It is static context, not a state tracker. Omit it if redundant. Studio-maintained project state remains exclusively in the project's wiki.

[Host notes](hosts/README.md) aid discovery, not instruction-file rewriting.
