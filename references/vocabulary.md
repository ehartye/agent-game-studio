# Suggested vocabulary

These examples are not closed sets or a required schema. Keep the project's terminology; older records need no automatic migration.

| Topic | Examples |
|---|---|
| Artifact status | draft, current, absent, reconstructed, conflicting |
| Backlog status | planned, in-progress, shipped, blocked, dropped |
| Asset progress | brief, draft, review, integrated, final |
| Fit assessment | supports the goal, tradeoff, unclear |
| Milestone | prototype, vertical slice, release candidate, ship |
| Criterion status | met, not-met, not-assessed |
| Evidence | observed, reported, none |
| Decision status | proposed, accepted, superseded, deprecated |
| Constraint status | not-yet-measured, at-risk, met, unmet, conceded |

Observed means an actual run or inspection supports the specific claim. Reported means an account reports it; none means no supporting evidence. An opinion is not an observed behavioral result. Unmeasured behavior remains not-assessed.

Approvals and concessions record real decisions. Use project decision authority, including delegation, and distinguish agent choices from personal owner approval.

Current means checked at the stated time. Reconstructed means derived after the fact from named sources. Conflicting means sources disagree. Blocked describes a real obstacle, not a missing Studio ceremony.

Historical phases, gate codes and sign-offs can remain as project history. Explain them when needed without forcing Studio vocabulary onto existing records.
